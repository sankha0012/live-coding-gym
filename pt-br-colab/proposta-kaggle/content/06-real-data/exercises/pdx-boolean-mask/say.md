I build each condition as a boolean Series and combine them with & and |, with parentheses because those operators bind tighter than the comparisons. Missing coupons are found with isna, since None and NaN are both missing and NaN never equals anything. A NaN total compares False with 100, so those rows pass only when the coupon is missing, which is what the rule says. I return a copy so later writes do not touch the caller's frame. For the shadow comparison, != treats two NaNs as different, so I subtract the rows where both are missing and cast the count to int. Both functions are vectorised and O(n).
