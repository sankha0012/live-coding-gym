I drop rows with a missing x for fitting, but I still learn a fallback from all labels, so predict never crashes on None. Then I try every observed value as the threshold in both directions and keep the most accurate pair, using a strict comparison so ties keep the first candidate and the result is deterministic. Brute force is O(n squared), fine for hundreds of rows; for large data I would sort once and sweep with running counts, which is O(n log n). The key point is that it is graded on a different sample, so I avoided anything that only memorises the training rows. In production I would also log how often the fallback is used, because a rising missing rate is a data problem, not a model problem.
