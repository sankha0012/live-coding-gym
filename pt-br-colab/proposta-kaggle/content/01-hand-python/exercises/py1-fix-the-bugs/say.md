There were three bugs. The return sat inside the loop, so only the first row was tagged. The second check was an if instead of an elif, so a None row was tagged "missing" and then compared with zero, which raises a TypeError. And the default argument was a list, which Python creates once, so every call kept appending to the same list. I fixed them with an elif, by moving the return out of the loop, and with the None-default idiom. The function is O(n) and does not touch the input. To catch this class of bug earlier I would run it on an empty list, a None row, and call it twice in a test.
