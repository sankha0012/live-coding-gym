y_true holds the real labels and y_pred the model's predictions, and zip walks them in pairs. Four counters start at zero. A prediction of 1 on a true 1 is a true positive, a prediction of 1 on a true 0 is a false positive, a prediction of 0 on a true 1 is a false negative, and everything else is a true negative. Going through the eight pairs gives 3 true positives, 1 false positive, 1 false negative and 3 true negatives, which the first print shows. Precision is tp divided by all predicted positives, 3 out of 4, which is 0.75. Recall is tp divided by all real positives, 3 out of 4, also 0.75. Accuracy is the correct predictions, tp plus tn, divided by the number of rows, 6 out of 8, which is 0.75. The f-string with :.2f rounds each value to two decimals and prints them on one line.

Q1: tp counts correct positive predictions, fp wrong positive predictions, fn missed positives and tn correct negatives; here they are 3, 1, 1 and 3.
Q2: They avoid dividing by zero when the model predicts no positives or there are no real positives, returning 0.0 instead of crashing.
Q3: With imbalanced data a model that always predicts the majority class gets high accuracy while its recall on the rare class is zero, so precision and recall are needed too.
