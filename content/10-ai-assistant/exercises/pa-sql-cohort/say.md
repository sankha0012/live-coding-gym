The model prompt gives the real table and column names, the date format and the SQLite dialect. It defines cohort, offset and retention exactly, so the assistant cannot invent its own meaning. It names the traps: distinct customers, cohort size including customers who never ordered, delivered orders only, and months computed from numbers. It asks for the output columns in order, for readable CTEs, and for sanity checks I can run to verify the result. A weak prompt such as "write a retention query" would get a plausible query with the wrong denominator.
