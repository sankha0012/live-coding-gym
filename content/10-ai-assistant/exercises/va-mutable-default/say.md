The bug is a mutable default argument. Python builds the default list once, when the function is defined, so every call without `log` shares and grows the same list. The fix is `log=None` and a new list inside the function. I use `is None`, not `not log`, because an empty list the caller passed must still be appended to in place. The habit: any `=[]`, `={}` or `=set()` in a signature is a red flag in AI code.
