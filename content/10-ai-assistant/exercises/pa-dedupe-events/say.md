The model prompt defines "duplicate" by event_id and says which copy wins, because "remove duplicates" alone is ambiguous. It gives a full ordering rule with a tie-break, so the output is deterministic and testable. It states the failure path for malformed events and the complexity target, which stops the assistant from writing a quadratic loop. A weak prompt would leave out the tie rules, the input shape, the error behaviour and the tests, and the code might look right while changing results between runs.
