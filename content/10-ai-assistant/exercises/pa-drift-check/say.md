The model prompt names the exact formula, the inputs and the output type, so the assistant cannot guess. It builds the bins from the reference sample only, which is the detail that makes PSI meaningful, and it handles empty bins with an epsilon, which is where most generated code crashes. It also states NaN, empty and constant inputs, and asks for tests and an explanation, so I stay in control and can check the result. A weak prompt such as "write a PSI function" would miss the binning rule, the zero-share problem, the open outer bins and any request for tests.
