The model prompt fixes the signature and the exact delays, so the output can be checked. It separates retryable errors from bad requests, which is what a real service needs. It injects `sleep`, so tests run fast and stay deterministic, and it says what happens after the last attempt. It asks for tests with a fake function and a recording sleep, and for an explanation of idempotency. A weak prompt such as "add retries to my API call" would miss the error types, the limit, the testability and the failure path.
