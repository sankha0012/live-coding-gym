The formula is easy to get almost right, so my first tests use a minimum that is not zero and a negative value; dividing by the max alone would pass on data that starts at zero. The dangerous inputs are the ones that break the division: constant values and a single value make max minus min equal to zero, and the spec says to return zeros, so I test that explicitly. The empty list is another edge, because min of nothing raises. I compare floats with pytest.approx, and I check the input list is not changed, since in-place rescaling would corrupt the raw data for later steps.
