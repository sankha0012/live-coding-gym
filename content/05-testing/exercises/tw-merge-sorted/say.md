I test the plain interleaving first, then the stability rule: the same key in both lists, with labels chosen so that a sort by label would give the opposite order. The classic merge bug is losing the leftovers when one list runs out, so I test both directions, since a bug may handle only one side. I also test empty inputs on each side. Finally I check both input lists are unchanged, because a merge that pops from its arguments destroys the caller's data and is also slow.
