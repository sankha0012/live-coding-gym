I turn every rule in the spec into one test, and in each invalid case I break only that rule so the failure points at it. One valid address proves the happy path. Then: no @ and two @, an empty local part, a domain with no dot, a domain starting with a dot and one ending with a dot, and spaces in either part. Rules like these are where implementations quietly drop a check, so each edge gets its own assert. I use `is True` and `is False` so a function returning a truthy non-bool does not slip through.
