I count true positives, false positives and false negatives in a pass over the pairs, then build each metric from those counts. Every division is guarded, so a model that never predicts positive gives precision 0 instead of a crash. The always-negative model on imbalanced data has high accuracy but recall 0, which is exactly why accuracy alone is misleading. It is O(n). The trade-off is that returning 0.0 for undefined precision hides the difference between "no positives predicted" and "all wrong", so in real code I would also log the counts.
