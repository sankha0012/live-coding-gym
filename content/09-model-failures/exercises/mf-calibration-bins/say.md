I assign each probability to a bin with floor(p * n_bins), capping 1.0 into the last bin so it does not create an extra bucket. I group in a dict, so empty bins never appear, then average the probabilities and the labels per bin. If mean predicted and observed rate are close in every bin, the model is calibrated. It is O(n log b) with the final sort. I validate the range first, because an out-of-range score would silently land in a wrong bin. A trade-off: bins with few cases give noisy rates, so I return the count to let the caller judge.
