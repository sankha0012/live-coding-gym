I compute the Pearson correlation of each feature with the label by hand: centre both lists, then divide the covariance sum by the square root of the product of the variance sums. I take the absolute value because a perfectly inverted feature leaks just as much. A constant feature would divide by zero, so I return 0 for it. It is O(f times n). A high correlation is a flag to investigate, not proof: a legitimate strong feature can also score high, so the threshold is a parameter.
