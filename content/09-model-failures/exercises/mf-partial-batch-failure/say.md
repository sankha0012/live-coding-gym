I loop over the rows with enumerate and wrap each call to the scoring function in try and except Exception. A good row appends its score, a bad row appends None and records its index and the exception name and message. That keeps the scores list the same length and order as the input, so the caller can zip them back to the rows. It is O(n) calls. The trade-off is that a systematic failure, where every row is bad, still returns a result, so the caller should alarm when the error rate is high.
