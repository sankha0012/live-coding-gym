There are two off-by-one errors. The slice values[i - window : i] stops before index i, so it leaves out the current value. The check i < window also hides the first full window, which ends at index window - 1. I spot this by running a tiny example by hand and checking the first and last outputs. The fix is the slice values[i - window + 1 : i + 1] and the check i < window - 1. The cost is O(n times window), and a running sum would make it O(n).
