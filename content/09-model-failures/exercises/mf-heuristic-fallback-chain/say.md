I loop over the model and the rule in order. Each call is wrapped in try and except, and a result of None counts as no answer. The first real value is returned with the name of the stage that gave it, otherwise I return the constant with "default". It is O(1) with at most two calls. I compare with None and not with truthiness, because a score of 0.0 is a valid answer. The trade-off is that catching every Exception can hide bugs, so in production I would also log which stage failed.
