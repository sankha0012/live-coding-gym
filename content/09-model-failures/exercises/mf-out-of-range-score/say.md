I clip each value with min and max, and I count only the values strictly below 0 or above 1. Exactly 0 and 1 are valid probabilities, so using non-strict comparisons would raise false alarms. It is O(n) time and space. I clip instead of dropping the row so the response keeps its shape, but I return the count so a monitor can alert, because a growing count means an upstream bug, not noise.
