This code checks one input row against a schema: each field must be present, have the right type and sit inside its range. It never raises on bad data. It returns the clean fields plus a list of error messages, so the caller sees every problem in one pass. validate_batch uses it to split rows into good rows and bad rows with their index. The cost is O(fields) per row, so O(rows times fields) for a batch. The risk is the type check: bool is a subclass of int in Python, so True passes as an age of 1, as the demo shows. The explicit NaN check matters too, because every comparison with NaN is false. I would reject bool on purpose and log the error counts, so a spike in bad rows raises an alert.
