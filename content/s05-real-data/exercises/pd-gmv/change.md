`gmv_by_city` gets an optional third parameter `statuses`, a tuple of status strings that defaults to `("delivered",)`. An order counts when its `status` is in `statuses`. Everything else stays the same: GMV is `subtotal + delivery_fee` with a missing subtotal as 0, the result is a Series indexed by `city`, largest first. For example `gmv_by_city(orders, restaurants, statuses=("delivered", "cancelled"))` also counts the cancelled orders. Calling `gmv_by_city(orders, restaurants)` behaves exactly as before.
