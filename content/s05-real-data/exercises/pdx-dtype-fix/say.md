I work on a copy so the caller's frame is not changed. pd.to_datetime turns the text into real timestamps, which unlocks hour and weekday later. For the coupon I keep the text only where the stripped value is not empty, so empty cells become NaN and later isna or fillna behave correctly. The three always-present ids go through astype int64, which fails loudly if a value is not a number, and that is what I want. It is linear in the rows. The courier id is the exception: it can be empty, and plain int64 cannot hold a missing value, so I convert it with to_numeric and the nullable Int64 type. The trade-off is that Int64 is a separate pandas type, so older code that expects floats with NaN may need care.
