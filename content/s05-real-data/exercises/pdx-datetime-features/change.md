`add_time_features` gets an optional second parameter `weekend_days`, a collection of weekday numbers (Monday is 0) that defaults to `(5, 6)`. The column `is_weekend` is `True` exactly for the orders whose weekday is in `weekend_days`. For example, `add_time_features(df, weekend_days=(4, 5))` marks Friday and Saturday as the weekend, so an order on Sunday gets `False` and one on Friday gets `True`. The columns `hour` and `weekday` do not change. Calling `add_time_features(df)` behaves exactly as before.
