I convert the text column to timestamps once with pd.to_datetime, then use the dt accessor to read hour and weekday. Pandas counts Monday as 0, so Saturday is 5 and Sunday is 6, and is_weekend is weekday at least 5. It is vectorised, so it is linear and fast, with no Python loop over rows. I work on a copy and leave created_at as it was. A trade-off is time zones: these timestamps have none, but with real data I would convert to the restaurant's local time first, because the hour depends on it.
