I convert created_at to datetime, sort by customer and time, and use groupby with shift(1) to get each customer's previous timestamp. This is the same idea as LAG with PARTITION BY in SQL. The difference divided by one day gives the gap in days. A customer's first order has no previous one, so it is NaN, which is correct and I leave it. The sort makes it O(n log n), and I reindex to the original order so the result lines up with the input rows.
