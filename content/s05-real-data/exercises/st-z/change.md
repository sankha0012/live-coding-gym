`two_prop_z` gets an optional fifth parameter `pooled`, a boolean that defaults to `True`. With `pooled=False` the standard error is the unpooled one, `sqrt(p1 * (1 - p1) / n1 + p2 * (1 - p2) / n2)`, using each group's own rate. The numerator is still `p2 - p1`. For example `two_prop_z(30, 200, 90, 400, pooled=False)` is about `2.289`, while the default (pooled) call gives about `2.165`. Calling without `pooled` behaves exactly as before.
