Orders have no city or cuisine, so I merge them from restaurants with a left join on restaurant_id and would check the row count stays the same. Then I pivot: city as rows, cuisine as columns, and a count as the value, with fill_value 0 so empty pairs show 0 and not NaN. It is O(n) for the merge and the count. Counting rows is not the same as summing ids, and I say that I count every status because the prompt says so.
