The bug is a missing filter. The function averages `actual_minutes` for every order with a known time and never checks that the status is "delivered". On the small example it looks right because the cancelled order has `None`, which the code already skips. A cancelled order with a number, for example 100 minutes, is counted and distorts the average. The fix is to add `o["status"] == "delivered"` to the list comprehension condition. I would keep the `is not None` check, and the `None` return for an empty list. The lesson is that a passing example does not prove the filter exists, so I test with a cancelled order that has a value.
