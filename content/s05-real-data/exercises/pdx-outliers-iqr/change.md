`iqr_outliers` gets an optional second parameter `k`, a number that defaults to `1.5`. It replaces the 1.5 in the fences, so a value is an outlier when it is below `Q1 - k * IQR` or above `Q3 + k * IQR` (still strict: a value exactly on a fence is not an outlier). For example, take the subtotals `[10, 11, 12, 13, 14, 25]`, where Q1 = 11.25, Q3 = 13.75 and IQR = 2.5. With `k=1.5` the upper fence is 17.5 and 25 is flagged. With `k=5` the upper fence is 26.25 and nothing is flagged. Calling `iqr_outliers(df)` behaves exactly as before.
