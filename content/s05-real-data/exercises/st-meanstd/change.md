`mean_std` gets an optional second parameter `ddof`, an integer that defaults to `1`. The standard deviation divides the sum of squared deviations by `n - ddof` instead of `n - 1`. So `mean_std(xs, ddof=0)` returns the population standard deviation: for `[2, 4, 4, 4, 5, 5, 7, 9]` it returns `(5.0, 2.0)`, while the default still returns `(5.0, 2.1381...)`. With `ddof=0` a list with a single value is allowed and gives a standard deviation of 0.0.
