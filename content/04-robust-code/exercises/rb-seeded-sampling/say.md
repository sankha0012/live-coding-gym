I make a private generator with random.Random(seed) and sample from it. That way the result depends only on the inputs, and other code that uses the global random module can neither change my sample nor be disturbed by it. Calling random.seed globally would work in a single script but break in a real service where other threads and libraries also draw numbers. Sampling is O(k) to O(n) depending on the algorithm. random.sample already raises ValueError for a bad k, which is the behaviour I want. Caveat: the exact numbers are stable for one Python version, so I would store the seed with the audit result.
