I take the iterator and cut it into chunks with islice, so memory stays at one chunk. I call the batch handler for the whole chunk, and only if it raises do I retry each record alone, so one bad record costs one error and not the whole chunk. Each error keeps the global index and the exception text, so we can find the record later. Time is O(n) calls in the good case and up to n plus n/chunk calls in the worst case. The trade-off is that the handler runs twice for a failing chunk, so it should be safe to repeat.
