I catch only a fixed tuple of transient exceptions, so permanent errors such as ValueError or FileNotFoundError propagate immediately and are not hidden by retries. Between attempts I wait base_delay times two to the power of the retry number, which is exponential backoff, and I never sleep after the last failure. The sleep function is injected, so tests run instantly. Worst case it makes retries plus one calls. In production I would add jitter so many clients do not retry at the same moment, and I would only retry calls that are safe to repeat.
