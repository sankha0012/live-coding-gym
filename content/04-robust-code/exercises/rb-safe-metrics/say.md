I filter out None and NaN first, then take the mean of what is left, and return None when nothing is left, so the caller can tell "no data" from a real zero. I check "is None" and isnan on purpose, because "if not v" would throw away valid zeros. safe_rate returns None for a zero or missing denominator instead of crashing or returning inf. It is O(n) time. The trade-off is that None must be handled downstream, but that is better than a silent fake 0 on a dashboard.
