RunningMean is a small class that tracks a name, a running total and a count. __init__ runs when an instance is created and stores the name, a total of 0.0 and a count of 0 on self. add updates the total and count and then returns self, which is what allows calls to be chained. mean returns 0.0 if nothing has been added, to avoid dividing by zero, and otherwise total divided by count. __repr__ defines how the object is printed: a string with the name in quotes (the !r), the count and the mean to two decimals. The script creates latency, adds 120 and 80 and prints it, so the mean is 100.00 over 2 values. It then prints a new empty instance, which shows a mean of 0.00. Finally it makes alias point at latency and adds 100 through it.

Answers. __init__ initialises a new instance's state, and self is that instance, so self.total belongs to one particular object. add returns self, so the result of the first call is the same object and a second method can be called on it straight away. alias = latency does not copy anything; both names refer to one object, so adding 100 through alias changes latency too, giving a count of 3 and a mean of (120 + 80 + 100) / 3, which is 100.0.
