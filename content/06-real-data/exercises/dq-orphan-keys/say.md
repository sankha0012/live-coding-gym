For each key I LEFT JOIN orders to the parent table and keep the rows where the parent key is NULL, which is the anti-join pattern. For couriers I first exclude a NULL courier_id, because cancelled orders have no courier by design. Delivered orders without a courier are a separate rule. Each check is O(n) with the primary-key index on the parent. In production I would also add foreign keys or a scheduled check so these rows are caught at load time.
