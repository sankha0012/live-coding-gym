I write one count per rule and stack them with UNION ALL, so the result is a small report that is easy to read and to alert on. Comparisons with NULL are never true, so cancelled orders with no actual_minutes are not flagged. Each rule is one O(n) scan. The thresholds like 150 are business choices, so I would keep them in a config table, and I would send the offending order ids to a quarantine table instead of only counting them.
