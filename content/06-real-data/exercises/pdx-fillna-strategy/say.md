I compute the median per restaurant with groupby and transform, which returns a series aligned to the original rows. I fill the missing subtotals with it, then fill whatever is still missing, which are restaurants with no known value, with the global median. I use the median and not the mean because order values are skewed and one huge order would drag the mean. It is one pass over the data. The trade-off is that filling hides the fact that data was missing, so in a real pipeline I would also keep a flag column.
