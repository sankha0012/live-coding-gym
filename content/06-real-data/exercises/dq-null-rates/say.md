I count NULLs per column with SUM(col IS NULL), divide by COUNT(*) and multiply by 100.0 so the division is not an integer division. I stack one row per column with UNION ALL and filter out the columns at zero. It is one pass per column, so O(n) each. A NULL is not always an error: coupon_code is empty by design, and courier_id is empty for cancelled orders. The number tells me where to look, not what is wrong.
