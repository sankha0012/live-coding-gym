I use corrwith to get the correlation of every feature with the label, take the absolute value so strong negative links count, and keep the names above the threshold. A constant column gives NaN, and NaN is never above the threshold, so it is not flagged. It is O(n times columns). This is only a first filter: a feature can leak and still have low correlation, and a high correlation can be honest. I would then ask when each flagged feature is known, before or after the prediction.
