I keep a dict of key to (value, stored_at) and always read time through the injected clock, so tests can move time without sleeping. Every operation first purges entries where clock minus stored_at is at least the TTL. On set I pop the key first, so replacing a key refreshes its age and never evicts a neighbour, then evict the first key in the dict, which is the oldest set time, if the cache is full. Purging is O(n) per call, which is fine for a small cache. For a big one I would use a heap or an OrderedDict with lazy expiry. I store a tuple so that a cached None is not confused with a miss.
