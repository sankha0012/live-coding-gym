I hash "experiment:user_id" with sha256 and turn the first 8 bytes into a number between 0 and 1, then scale it by the total weight and walk the cumulative weights to pick a variant. The same input always gives the same bucket, so users are sticky without storing anything. Putting the experiment name in the hash makes experiments independent of each other. I avoid hash() because Python randomises string hashes per process, and I validate the weights up front. It is O(number of variants) per call. The trade-off is that changing the weights later moves some users between variants.
