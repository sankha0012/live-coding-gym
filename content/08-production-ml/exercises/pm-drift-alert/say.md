I keep one boolean, active, and two thresholds. The alert raises only when inactive and the score is above high, and clears only when active and the score is below low, so scores inside the band change nothing. That stops flapping when the metric hovers around a single line. Each update is O(1) and returns an event, so the caller can page only on "raised". The trade-off is that a wide band delays clearing; I would pick low from how noisy the metric is, and I could also require several consecutive scores before changing state.
