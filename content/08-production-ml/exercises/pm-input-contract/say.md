I loop over the contract in order so the violations come out in a stable order and unknown request fields are dropped for free. For each field I check missing first, then type (rejecting bool explicitly), then range, and I collect every violation instead of stopping at the first. Fields that fail never reach the clean dict, so the model only sees valid input. It is O(number of contract fields). The trade-off is that I report problems instead of raising, so the caller decides whether to return a 422 or fall back to a default.
