I read the version first and refuse anything unknown, because guessing a shape silently corrupts data. Each version has its own checks, and v1 is upgraded to the current shape so the rest of the code only handles v2. For the money conversion I use round, since int(19.99 * 100) gives 1998. I return a new dict so the caller's payload is not mutated, and I drop extra keys. It is O(1). The trade-off is strictness: rejecting bad payloads loudly is safer than guessing, but in production I would send them to a dead-letter queue and count them.
