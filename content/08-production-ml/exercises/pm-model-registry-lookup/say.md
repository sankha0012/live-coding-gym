I filter by name and stage, turn each version into a tuple of integers, and keep the record with the largest tuple. Comparing strings would put "1.9.0" above "1.10.0", so numeric tuples are the key point. I pad short versions with zeros so "2.1" equals "2.1.0", and I use a strict greater-than so a tie keeps the first record. It is one pass, O(n) time and O(1) extra space. Raising LookupError when nothing matches makes a missing production model a loud failure instead of a silent None.
