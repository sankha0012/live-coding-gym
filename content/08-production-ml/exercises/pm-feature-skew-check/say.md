I loop over the sorted union of feature names so features missing on either side are reported, not silently skipped. For features in both, I handle nulls first, because nan never equals itself, then compare numbers with an absolute tolerance and everything else with equality. Exact equality on floats would flag harmless rounding noise from different pipelines. It is O(n log n) for the sort, and the output is sorted so alerts and tests are stable. The trade-off is that an absolute tolerance is wrong for features with very different scales, so a real system might use a relative tolerance per feature.
