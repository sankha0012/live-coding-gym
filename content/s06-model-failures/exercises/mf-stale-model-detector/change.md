Add an optional parameter `grace_days=0.0`. A value is stale only when its age is strictly greater than its limit plus `grace_days`, and this applies to both the model and the data. The returned ages are unchanged. For example, with a model age of 31 days and `max_model_age_days=30`, `grace_days=2` makes `model_stale` false, while a model age of 33 days with the same settings is stale. With the default of `0.0` nothing changes.
