A DataFrame has five users; b and d have no income (None becomes NaN). The raw mean skips NaN, so it is (4000 + 5200 + 4800) / 3 = 4666.7. filled replaces NaN with 0, so the mean becomes 14000 / 5 = 2800.0. The count of filled values below 2000 is 2, the two zeros. Then the median of the real values (4800) is used to fill instead, and the count below 2000 is 0. The last line counts the original missing values: 2.

Answers. fillna(0) turns "we do not know" into "earns nothing". The mean drops from 4666.7 to 2800.0, and the two unknown users are counted as low income, which could send them to a rule or a model as if they were poor. If the data has missing incomes that are not truly zero, which is the usual case, every statistic and every downstream decision is shifted, with no error. The median fill is a better default because it keeps the typical scale, but it still hides the fact that the value was missing, so a careful pipeline keeps an extra was-missing indicator column, computes the fill value on training data only, and uses the same value at serving time, otherwise train and serve disagree.
