Add an optional parameter `top_k=None`. When it is a number, return at most that many names: the first `top_k` of the usual ordering (highest absolute correlation first, ties by name). `top_k=0` returns `[]`. The length check still applies to every feature. For example, if three features are leaky and come out as `["a", "b", "c"]`, then `top_k=2` returns `["a", "b"]`. With the default `None` nothing changes.
