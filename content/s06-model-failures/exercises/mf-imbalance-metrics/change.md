Add an optional parameter `positive=1`: the label that counts as the positive class. Precision, recall and f1 are then computed for that label, and everything that is not that label counts as negative. Accuracy does not change. For example, with `y_true = [0, 0, 0, 0, 1]` and `y_pred = [0, 0, 0, 0, 0]`, `binary_metrics(y_true, y_pred, positive=0)` gives precision 0.8, recall 1.0 and f1 of 8/9, while the default `positive=1` still gives 0.0 for all three.
