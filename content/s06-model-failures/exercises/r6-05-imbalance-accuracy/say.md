Answers. The accuracy is 0.95 because 95 percent of the labels are the majority class, so a constant answer scores high while finding none of the cases that matter. If the data is 95 percent one class, accuracy rewards ignoring the rare class; use recall, precision, F1 or PR-AUC, and compare against the always-majority baseline. The guard on precision is needed because with no positive predictions the denominator is zero, which would raise ZeroDivisionError in plain Python or give nan in numpy; the code picks an explicit value and the reader should know it is a choice.
