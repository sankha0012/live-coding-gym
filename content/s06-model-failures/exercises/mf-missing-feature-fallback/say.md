I copy the row, then loop over the defaults and fill any feature whose value is absent or None. I test with `is None`, not truthiness, because 0 and False are real values and must survive. I return the sorted list of filled names so the output is deterministic and the caller can log or count fallbacks. It is O(f) for f features. The trade-off is that defaults can bias scores, so a high fill rate should alert rather than be quietly accepted.
