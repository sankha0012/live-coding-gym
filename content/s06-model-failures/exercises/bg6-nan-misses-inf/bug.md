The guard rejects non-numbers, bools and NaN, but it checks `math.isnan` and never `math.isfinite`, so `float('inf')` and `float('-inf')` are treated as good scores. Infinity is a valid float and is not NaN, so the check lets it through. The clean list then still holds infinite scores and the bad count is too low, so a downstream threshold or average receives a value the guard was meant to remove.
