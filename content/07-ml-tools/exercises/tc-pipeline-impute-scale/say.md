I chain the imputer, the scaler and the classifier in one Pipeline, so one fit call learns every statistic from the training data only. The order matters: the imputer comes first so the scaler never sees a NaN. I use the median because it is robust to outliers. A pipeline also stops leakage in cross validation, because each fold refits every step. The trade-off is that the steps are hidden behind names, so I give them clear names to read the fitted values later.
