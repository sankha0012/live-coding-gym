A tracker such as MLflow logs the parameters, metrics, model files and code version of every run, in one place I can search and compare. In a spreadsheet someone has to type the numbers, so rows get missed or mistyped, and the row rarely links to the exact model file or data that produced it. Say the model in production starts to behave oddly: with a tracker I can open its run and see the parameters, the metrics and the artifact, and I can reproduce it. I can also sort runs by validation score or compare two learning rates without rebuilding a table. The limit is that a tracker does not improve the model, and it only helps if the team logs every run in the same way.
