I run each check inside try/except so one broken dependency cannot crash the health endpoint, and an exception or an unexpected return value counts as down. I map the statuses to numbers, ok 0, degraded 1, down 2, and keep the maximum, which makes the aggregation order-independent. I also collect a reason for every non-ok check, so whoever gets paged sees all the problems, not only the first. It is O(number of checks), plus the cost of the checks themselves. In real life I would add a timeout per check, because a hanging check is worse than a failing one.
