I write the fitted pipeline with joblib.dump and read it back with joblib.load, which is the usual way for scikit-learn objects because it handles large numpy arrays well. Saving the whole pipeline, not only the classifier, keeps the imputer and scaler with the model, so serving cannot apply different preprocessing than training. The trade-off is that a joblib file is a pickle: only load files you trust, and load it with the same scikit-learn version that saved it. For safety in production I would also record the version next to the file.
