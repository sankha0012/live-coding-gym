A version 1 payload may now carry an optional `currency` key. If it is present and is a `str`, use it as the `currency` of the upgraded result instead of `"BRL"`. If it is missing, or is not a string, the currency is still `"BRL"`. For example, `{"version": 1, "user_id": "u", "amount": 2.5, "currency": "USD"}` becomes `{"version": 2, "user_id": "u", "amount_cents": 250, "currency": "USD"}`. Version 2 handling does not change.
