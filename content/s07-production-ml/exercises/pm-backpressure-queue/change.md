Add a method `put_many(items) -> int` to your `BoundedQueue`. It puts each item of the iterable `items` with the queue's current policy, in order, and returns how many of them were accepted. For example, with `BoundedQueue(2, "reject")` holding nothing, `put_many([1, 2, 3])` returns `2`, and the queue holds `1, 2` with `dropped == 1`. With the default `drop_oldest` policy every item is accepted, so the same call returns `3`, and the queue holds `2, 3`.
