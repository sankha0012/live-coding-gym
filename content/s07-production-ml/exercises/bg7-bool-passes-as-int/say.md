Two checks are missing, and both come from Python behaviour. First, `bool` is a subclass of `int`, so `isinstance(True, int)` is true and a JSON `true` passes as an age or a count. I need to exclude bool explicitly for int and float fields. Second, `nan` is not equal to or ordered against anything, so `nan < min` and `nan > max` are both false and a `nan` passes every range check. The spec says nan is always out of range, even with no bounds, so I test it with `math.isnan` before the bounds. I fixed both and reran the tests, including a bool on a float field and a nan with no bounds. At a trust boundary these are exactly the values that would corrupt predictions without raising anything.
