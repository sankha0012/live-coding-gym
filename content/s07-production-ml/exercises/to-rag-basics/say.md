"Retrieval-augmented generation first searches your own documents for passages relevant to the question, usually by comparing embeddings, and then puts those passages in the prompt so the model answers from them. It gives the model current or private knowledge, such as a company's help articles, without retraining it, and it can cite sources. The first failure mode is retrieval: documents are split badly, or the right passage is not in the top results, so the model never sees it. The second is generation: the model ignores the context, mixes it with its own memory, or answers confidently when the context has no answer. Stale or duplicated documents also cause wrong answers. RAG reduces hallucination but does not remove it, so I evaluate retrieval, for example whether the right passage is in the top results, separately from answer quality."
