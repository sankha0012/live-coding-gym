I put the scaler and the model in one Pipeline and give it to cross_val_score, so every fold fits the scaler on its training part only. If I scaled all of X first, the test folds would leak their mean and spread into training and the score would look too good. I use StratifiedKFold so each fold keeps the class ratio, which matters when one class is rare, and I fix the seed so the number repeats. The cost is five model fits. The trade-off is that the mean hides the spread between folds, so in a real report I would also show the standard deviation.
