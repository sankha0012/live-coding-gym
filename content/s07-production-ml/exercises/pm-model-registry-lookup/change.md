Add an optional fourth parameter `max_version: str | None = None` to `latest_version`. When it is given, records whose version is higher than `max_version` are ignored (a version equal to it is fine), and the highest remaining version is returned. Compare with the same rules as before, so `"2.1"` equals `"2.1.0"`. For example, with versions `1.9.0`, `1.10.0` and `2.0.0` in production, `max_version="1.10"` returns the `1.10.0` record. If nothing is left, raise `LookupError` as before. Without `max_version` nothing changes.
