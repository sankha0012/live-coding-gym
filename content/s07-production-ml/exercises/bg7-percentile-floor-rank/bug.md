The assistant computed the rank as `int(p / 100 * n)`, which rounds down and is also used as a zero-based index. Nearest rank needs `ceil(p / 100 * n)` as a one-based rank, so the code returns the value one position too high whenever the product is a whole number, for example p95 of 1 to 100 gives 96 instead of 95. A latency dashboard then reports tail latencies that are slightly too high, and alert thresholds fire at the wrong point.
