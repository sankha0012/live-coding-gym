Write `first_index(nums: list[int], target: int) -> int`. `nums` is sorted ascending and may contain duplicates. Return the index of the first (leftmost) occurrence of `target`, or `-1` if it is not there. Use binary search, not a linear scan. An empty list returns `-1`.

Example: `first_index([1, 2, 2, 2, 3], 2)` returns `1`.
