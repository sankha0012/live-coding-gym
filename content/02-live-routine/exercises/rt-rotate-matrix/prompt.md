Write `rotate(m: list[list[int]]) -> list[list[int]]` that rotates an n x n matrix 90 degrees clockwise and returns a NEW matrix. Do not change the input. An empty matrix `[]` returns `[]`. You may assume the matrix is square.

Example: `rotate([[1, 2], [3, 4]])` returns `[[3, 1], [4, 2]]`. The first column read from the bottom becomes the first row.
