Write `roman_to_int(s: str) -> int` for a valid uppercase Roman numeral. Values: I=1, V=5, X=10, L=50, C=100, D=500, M=1000. A smaller value written before a larger one is subtracted (IV is 4, IX is 9, XL is 40, XC is 90, CD is 400, CM is 900). An empty string returns 0. Input is always valid, so you do not need to check it.

Example: `roman_to_int("MCMXCIV")` returns `1994`.
