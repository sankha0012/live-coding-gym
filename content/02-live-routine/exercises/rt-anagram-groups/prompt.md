Write `anagram_groups(words: list[str]) -> list[list[str]]`. Group the words that are anagrams of each other (same letters, same counts). Words are lowercase. Inside a group keep the input order, and keep duplicates. Return the groups sorted by their first word. An empty list returns `[]`.

Example: `anagram_groups(["tea", "eat", "tan", "ate", "nat", "bat"])` returns `[["bat"], ["tan", "nat"], ["tea", "eat", "ate"]]`.
