I use an OrderedDict, which keeps keys in order of use. The oldest key is at the front and the newest at the back. On get I move the key to the back and return its value, or return -1 if it is missing. On put I set the value, move the key to the back, and if the size is over capacity I pop from the front. Every operation is O(1). By hand, the same idea is a dict plus a doubly linked list. The trap is forgetting that get also counts as a use.
