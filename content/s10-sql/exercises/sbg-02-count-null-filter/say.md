The WHERE clause filters rows before the aggregates run. Cancelled orders have a NULL actual_minutes, so they are all removed and the cancelled row disappears, and total_orders and with_coupon only see the rows that have actual_minutes. COUNT(actual_minutes) already skips NULLs by itself, so no WHERE is needed. I removed it and checked that both statuses come back and that total_orders equals COUNT(*) on the whole table.
