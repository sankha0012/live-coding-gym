NOT IN compares with every value in the list, and a comparison with NULL is unknown, not true. The orders table has a delivered order with a NULL customer_id, so the subquery returns a NULL and NOT IN never becomes true, so the result is empty. I rewrite it with NOT EXISTS and a correlated subquery, which only looks for a matching order and ignores NULL keys. I checked that the new result is not empty and includes customers with only cancelled orders.
