For output I call json.dumps with sort_keys=True so the text is deterministic, and separators of comma and colon with no spaces to make it compact. For input I call json.loads inside a try and catch JSONDecodeError, returning None. Both are O(n) in the size of the data. The trade-off is that None hides the reason for the failure, so in real code I would log it or raise a clear error.
