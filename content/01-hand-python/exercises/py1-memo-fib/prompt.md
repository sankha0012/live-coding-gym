Write `fib(n, cache={})` that returns the n-th Fibonacci number with `fib(0) == 0` and `fib(1) == 1`. n goes up to 90. Use the `cache` dict as the memo: for `n >= 2`, store the result in `cache[n]` and reuse it when it is there. Keep the default `{}` in the signature so the cache lives across calls. A caller may pass its own dict to start from a clean cache. Each value must be stored only once, so calling `fib(n, cache)` a second time with the same dict stores nothing new.
