Write `set_diff_report(old, new) -> dict` where `old` and `new` are lists of strings, possibly with duplicates. Return a dict with three keys, each a sorted list without duplicates: `"added"` (in `new` but not in `old`), `"removed"` (in `old` but not in `new`) and `"kept"` (in both). `set_diff_report(["a", "b"], ["b", "c"])` returns `{"added": ["c"], "removed": ["a"], "kept": ["b"]}`. Two empty lists give three empty lists.
