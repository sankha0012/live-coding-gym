I number each customer's delivered orders from newest to oldest, with order_id as a tie-break so the choice is deterministic. A window function cannot be filtered in the same SELECT, so I wrap it in a subquery and keep rn = 2. Customers with one order never get an rn of 2, so they drop out by themselves. It is one sort of the orders, so O(n log n). The tie-break matters: without it two orders with the same timestamp could swap places.
