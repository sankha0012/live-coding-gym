There are three promises in the spec, so I write at least one test for each. First, duplicates are removed. Second, the first occurrence wins and the order is kept, so I use an unsorted input like 3, 1, 2, 3, 1; a version that uses set() loses the order, and one that keeps the last occurrence gives a different list. Third, the input is not mutated, so I copy the data into a variable, call the function, and compare the variable afterwards. I add the empty list and the no-duplicates case as cheap edge checks.
