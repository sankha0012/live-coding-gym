Add an optional third parameter `keep_extra=False`: `validate(row, schema, keep_extra=False)`. When it is `True`, fields that are not in the schema are also copied, unchanged, into the clean row, and they are still reported as `extra:<field>` in the issues. For example, with the schema `{"hour": ("int", 0, 23, 12)}`, `validate({"hour": 5, "promo": "x"}, schema, keep_extra=True)` returns `({"hour": 5, "promo": "x"}, ["extra:promo"])`. With the default `False`, extra fields are reported but dropped, as before. The input row must still not be modified.
