I start with the behaviour in the spec: a small list where I can compute every window by hand, so an off-by-one at the end shows up as a missing last item. Then the edges: a window equal to the length gives exactly one mean, a window larger than the list or an empty list gives an empty list, and a window below 1 must raise ValueError, which I check with pytest.raises. Finally I check that the input is not modified, using unsorted data and comparing it afterwards. Each test checks one behaviour, so a failure names the bug.
