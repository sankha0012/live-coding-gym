Add an optional second parameter `limit=None`: `rank(records, limit=None)`. When `limit` is a number, return only the first `limit` records of the ranked order, for example the top 3. `limit=0` returns `[]`, and a `limit` larger than the number of records returns all of them. With the default `None`, nothing changes. The ranking rules stay exactly the same, and the input must still not be modified.
