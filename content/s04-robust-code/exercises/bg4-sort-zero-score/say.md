The bug is a truthiness check where the code needs an `is None` check. `not r["score"]` is true for `None`, but also for `0`, so a record with a score of zero is treated as missing and sorted behind records with negative scores. The fix is to write `r["score"] is None` in the first part of the key. I would also add a test with a score of exactly zero and one negative score, because that is the case the original tests missed. The habit: when a value can legitimately be zero, never use `not x` to mean "is missing".
