I never use real sleep: I inject a fake that appends to a list, so the test is fast and I can assert exactly how many times and with what value it was called. I build a small flaky function that fails a set number of times and counts its calls. Then I test: success on the first try with no sleeps, success after two failures with two sleeps, and all attempts failing, where I check that the call count equals tries, that the last error is raised with pytest.raises, and that there is no sleep after the final failure. A single-try case covers the boundary. Those checks catch an extra sleep, one attempt too few, and a swallowed error.
