I validate in __post_init__ so an invalid Order can never exist: if the object is built, it is valid. I collect every problem in a list and raise one ValueError at the end, so the caller sees all the issues in one go instead of fixing them one at a time. I check types first, and I reject bool and NaN explicitly, because True is an int and NaN passes "less than" checks silently. It is O(1) per record. The trade-off is that a dataclass is mutable, so later assignments are not checked unless I use frozen=True.
