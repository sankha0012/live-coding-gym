Add an optional third parameter `indent=None`: `atomic_write_json(path, obj, indent=None)`. It is passed on to the JSON writer so the file can be pretty printed. After `atomic_write_json(p, {"a": [1, 2]}, indent=2)` the text of the file is exactly what `json.dumps({"a": [1, 2]}, indent=2)` returns. With the default `None` the file is written as before. The failure rules do not change: on any error the old file stays as it was and no temporary file is left.
