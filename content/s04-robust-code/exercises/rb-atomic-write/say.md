I never write to the target directly. I write to a temp file in the same directory, flush and fsync it, then call os.replace, which swaps the file in one step, so readers see either the old file or the new one, never half of it. If serialisation fails, I delete the temp file and re-raise, so the old file is untouched. The temp file must be on the same filesystem, otherwise the rename is not atomic. The cost is O(size of the data) and a short window with two copies on disk.
