Add an optional fourth parameter `exclude=()`: `sample_ids(ids, k, seed, exclude=())`. Items whose value is in `exclude` can never be picked. The `k` checks now apply to the items that are left, so `sample_ids(["a", "b", "c"], 3, 1, exclude=["b"])` raises `ValueError`, while `sample_ids(["a", "b", "c"], 2, 1, exclude=["b"])` returns `a` and `c` in some order. Without `exclude`, nothing changes. The result must still be repeatable for the same arguments, and `ids` must still not be modified.
