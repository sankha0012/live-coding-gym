A record is a flat dict with a few fixed keys plus the caller's fields, so a log system can filter on any of them. I validate the level and event first, and I reject reserved names in the fields, because a silent overwrite would let a field called level hide the real severity. The timestamp comes from an injected clock, which keeps the function pure and testable, and I call it once so one record has one time. Building a new dict leaves the caller's fields untouched. Cost is O(number of fields). The trade-off is raising on collision instead of renaming the key, which is stricter but makes bugs visible.
