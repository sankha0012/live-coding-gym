This code assigns users to experiment variants so that the same user always gets the same variant, without storing anything. It hashes the experiment name together with the user id using sha256, takes the first eight bytes as an integer, and keeps the remainder by 10,000 as the bucket. The variants are then cut points on that range according to their weights. The cost is O(v) for v variants, and there is no database lookup. I use hashlib and not the built-in hash, because hash of a string changes between Python processes and would reassign users on every restart. Including the experiment name in the key makes the buckets independent across experiments, so the same users are not always in treatment. The risk is changing the setup while the test runs. If I change the weights, or rename the experiment, users move between variants and the results are contaminated.
