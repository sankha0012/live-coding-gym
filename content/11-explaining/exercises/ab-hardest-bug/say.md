Worked sample: "A daily report showed conversion up by ten percent overnight, with no product change. It was hard because the code had not changed and the numbers were only wrong for some days. First I recomputed one day by hand on a small sample and the sample matched the old number, so the problem was in the data. Then I compared yesterday's rows with last week's and found that a source system had started to send some records twice. The root cause was that our join assumed one row per order, so duplicates were counted twice. I deduplicated on the order id before the join, and I added a check that fails the job if order ids are not unique. The lesson was to assert the shape of the data at the start of a pipeline, not to trust it."
