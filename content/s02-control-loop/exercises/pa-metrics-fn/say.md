The model prompt gives the formulas and the output shape, and it makes the zero-division rule explicit: return 0.0, no exception and no NaN. That is the edge case an interviewer will probe, because a model that predicts no positives is a common failure. It also validates input lengths and asks for tests checked against a hand calculation, so I can verify the numbers myself. A weak prompt such as "compute precision and recall" would leave the zero case undefined and might pull in sklearn, which the task did not ask for.
