Write `word_count_top(text: str, n: int) -> list` that returns the `n` most common words as a list of `(word, count)` tuples. Split `text` on whitespace and lowercase every word; do not strip punctuation. Sort by count, highest first. Words with the same count are ordered alphabetically. If there are fewer than `n` distinct words, return all of them. Empty text returns an empty list.
