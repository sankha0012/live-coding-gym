Write `top_k(items: list, k: int) -> list` that returns the `k` most frequent items, most frequent first. Items with the same count are ordered by first appearance in `items`. If `k` is larger than the number of distinct items, return all of them. If `k` is 0 or `items` is empty, return an empty list.

Example: `top_k(["b", "a", "b", "c", "a", "d"], 2)` returns `["b", "a"]`. Both appear twice, and `"b"` appeared first.
