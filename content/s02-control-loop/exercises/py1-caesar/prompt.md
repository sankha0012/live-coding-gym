Write `caesar(s: str, shift: int) -> str` that shifts every letter by `shift` places in the alphabet. Keep the case of each letter. Wrap around, so `"z"` shifted by 1 is `"a"`. Only the English letters a-z and A-Z are shifted. Every other character, including digits and accented letters like `é`, stays unchanged. The shift can be negative or larger than 26. `caesar("Abc, xyz!", 3)` returns `"Def, abc!"`. An empty string returns an empty string.
