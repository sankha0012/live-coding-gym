Add an optional fourth parameter `drop_short=False`. When it is `True`, leave out every chunk that has fewer than `size` words, so only full-size chunks are returned. With the default, behaviour is unchanged. Example: `chunk_words("a b c d e", 2, 0, drop_short=True)` returns `["a b", "c d"]` (the lone `"e"` is dropped), and `chunk_words("a b", 5, 2, drop_short=True)` returns `[]`.
