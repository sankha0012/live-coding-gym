Write `longest_unique(s: str) -> int` that returns the length of the longest substring of `s` with no repeated character. A substring is a run of neighbouring characters. An empty string returns 0. Case matters, so `"a"` and `"A"` are different characters.

Example: `longest_unique("abcabcbb")` returns `3`, because `"abc"` is the longest run with no repeat.
